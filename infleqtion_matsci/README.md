# Running a logical material science VQE on Infleqtion's Sqale

1) Install the necessary packages to run the tutorial notebook by running `pip install -r requirements.txt` on the `requirements.txt` file in this directory.
2) Run the Jupyter notebook `infleqtion_logical_aim.ipynb` using the environment with the installed packages
3) [Subject to hardware availability] Create an account on superstaq.infleqtion.com to obtain your Superstaq API key to access Infleqtion's compiler and hardware
